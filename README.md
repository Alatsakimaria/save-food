# Save Food

## What It Does

Save Food is a platform that connects bakeries and food stores with customers to reduce food waste.

- Bakeries and stores create "food boxes" with unsold items at discounted prices
- Customers search for and reserve available boxes nearby
- Store managers have a dashboard to manage boxes and handle reservations

## Why It Matters

- Reduces food waste from unsold inventory
- Helps customers save money on quality food items
- Creates an additional revenue stream for bakeries and stores

## Target Users

- Bakeries and food stores looking to reduce waste and increase sales
- Budget-conscious customers seeking discounted food

## Quick Start

### Installation
```bash
make install
```

### Running the App
```bash
make run
```

This starts:
- Backend: http://localhost:8080
- Frontend: http://localhost:4200

### Available Commands
```bash
make help          # Show all available commands
make build         # Build the application
make test          # Run tests
make clean         # Remove build files
```
